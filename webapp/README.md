# هفته‌نگار | وب‌اپ نصب‌پذیر

نشانی وب‌اپ: https://haftehnegar-pwa.zh13.workers.dev/

## امکانات

- جدول هفتگی قابل ویرایش، تقویم شمسی و مناسبت‌های منتخب آفلاین
- قالب‌های آماده و قالب‌ساز، پیش‌نمایش و زوم
- آرشیو «برنامه‌های من» با دو بخش شخصی و دیگران
- خروجی PNG و PDF افقی؛ سؤال ذخیره پس از خروجی
- ذخیره پیش‌نویس و آرشیو در فضای محلی همان مرورگر و همان دامنه، همراه با پشتیبان JSON
- نصب از مرورگر (PWA) و اجرا بدون اینترنت پس از یک بار دریافت و تکمیل کش سرویس‌ورکر

## انتقال برنامه‌ها

در نسخه قدیمی HTML یا APK، از بخش آرشیو یک فایل پشتیبان JSON بگیرید و از گزینه «واردکردن پشتیبان» در وب‌اپ استفاده کنید. اطلاعات داخل APK یا file:// به‌صورت خودکار به وب‌اپ منتقل نمی‌شوند.

## راه‌اندازی محلی

فایل‌های پوشه `webapp/` را روی یک سرور HTTPS یا `http://localhost` قرار دهید. ثبت Service Worker و قابلیت نصب در نمایشگر محلی فایل `file://` فعال نمی‌شوند.

## محدودیت

داده‌ها بین مرورگرها یا دستگاه‌ها همگام نمی‌شوند و با پاک‌کردن داده‌های سایت از بین می‌روند. از آرشیو به‌طور دوره‌ای پشتیبان JSON بگیرید. بارگذاری مناسبت‌های تکمیلی تقویم ممکن است به اینترنت نیاز داشته باشد.

پوشه `webapp/` منبع انتشار وب است. کدهای اندروید قبلی برای بایگانی باقی مانده‌اند، ولی نسخه اصلی پروژه وب‌اپ است.
